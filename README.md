# Tricentis Automation

Учебный проект по автоматизации тестирования веб-приложения
[Tricentis Demo Web Shop](https://demowebshop.tricentis.com/) на Java.

Проект демонстрирует построение фреймворка с использованием паттерна
Page Object Model, позитивные и негативные проверки, а также проверку
бизнес-логики (сортировка товаров).

## Стек

| Технология | Версия | Назначение |
|------------|--------|------------|
| Java | 17 | Язык программирования |
| Selenium WebDriver | 4.x | Управление браузером |
| TestNG | 7.x | Фреймворк для тестов |
| Maven | 3.x | Сборка проекта и зависимости |
| Page Object Model | — | Паттерн организации кода |

## Структура проекта
```
src/test/java/
├── base/
│   └── BaseTest.java # Запуск и закрытие браузера (@BeforeClass / @AfterClass)
├── data/
│   └── User.java # Модель тестовых данных пользователя
├── pages/
│   ├── HomePage.java # Главная страница
│   ├── RegisterPage.java # Страница регистрации
│   ├── LoginPage.java # Страница входа
│   └── CategoryPage.java # Страница категории товаров (сортировка)
└── tests/
    ├── FirstTest.java # Проверка главной страницы
    ├── RegisterTest.java # Регистрация нового пользователя
    ├── LoginTest.java # Вход с валидными и невалидными данными
    └── SortByPriceTest.java # Сортировка товаров по возрастанию цены
```

## Список тестов

| Тест | Тип | Что проверяет |
|------|-----|---------------|
| `testHomePageTitle` | Позитивный | Заголовок главной страницы содержит «Welcome» |
| `testRegistration` | Позитивный | Регистрация нового пользователя с уникальным email |
| `testLogin` | Позитивный | Вход с валидными данными, проверка признаков авторизации |
| `testLoginWithWrongPassword` | **Негативный** | Вход с неверным паролем: появляется ошибка, пользователь не авторизован |
| `testSortByPriceLowToHigh` | Позитивный | Цены товаров в категории идут по возрастанию после сортировки |

## Как запустить

### Требования
- JDK 17+
- Maven 3.8+
- Google Chrome (последняя версия)

### Запуск всех тестов

```bash
mvn clean test
```
### Запуск одного теста
```bash
mvn clean test -Dtest=SortByPriceTest
```

## Запуск через IntelliJ IDEA

1. Открыть проект через pom.xml.
2. Дождаться загрузки зависимостей Maven.
3. Нажать правой кнопкой на нужный тестовый класс → Run.

## Особенности реализации

· Page Object Model — локаторы и действия вынесены в отдельные классы,
тесты не зависят от структуры страницы.
· Явные ожидания (WebDriverWait) — используются вместо Thread.sleep()
для стабильности тестов на динамических страницах.
· Уникальные тестовые данные — email генерируется через
System.currentTimeMillis(), чтобы избежать конфликтов при повторной регистрации.
· Негативное тестирование — проверяется не только «счастливый путь»,
но и корректная обработка ошибок.
· Скрытие признаков автоматизации — используется опция
--disable-blink-features=AutomationControlled, чтобы сайты не блокировали
запросы от Selenium.
